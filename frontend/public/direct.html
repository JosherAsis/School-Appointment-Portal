Common Features

  • Student Registration: Create a new student account
  • Book Appointments: Schedule meetings with administrators
  • View Appointments: See your upcoming and past appointments
  • Admin Dashboard: Manage appointments and students (admin only)

Troubleshooting

If you're experiencing issues with the main application, try these steps:

  1. Check if the backend server is running
  2. Clear your browser cache and cookies
  3. Try using a different browser
  4. Check your internet connection
  5. Use the API test page to verify connectivity
